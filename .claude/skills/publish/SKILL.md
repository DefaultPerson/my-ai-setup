---
name: publish
description: Publish the current repository to GitHub, or review and update its GitHub setup.
disable-model-invocation: true
---

Use `git` and authenticated `gh`; inspect `origin` and the GitHub repository first.

- A new repository is private unless asked otherwise. A review alone changes nothing.
- Apply only the requested changes; a license, Pages, CI or Dependabot only when in scope. Ask only for missing choices.
- Report the repository URL and what changed.
